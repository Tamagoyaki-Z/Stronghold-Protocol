# 我们的分支开发记录

本目录属于 LongQianChen 的 `feat/IncreasePlayerCapacity` 分支，保存本地开发的需求、决定、实现依据、验证结果和后续工作。上游原有文档保持现有路径；今后的分支开发记录集中写在这里。

## 接手时先看什么

1. 阅读本页的状态和待办，确认记录对应的代码版本。
2. 阅读 [开发流程](WORKFLOW.md) 和与任务有关的 [已确认决定](DECISIONS.md)。
3. 在 [记录索引](records/README.md) 找最近一次相关开发，按其中的代码、测试和提交继续核实。
4. 合并新版本时另读 [上游同步流程](UPSTREAM.md)。执行范围与权限以用户当前要求和适用的 AGENTS.md 为准，本目录不替代它们。
